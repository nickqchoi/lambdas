# UI Style Guide: Blue & White Theme

## Philosophy
The app uses a clean, modern aesthetic similar to premium iOS/social apps. The core color story is "Sky & Cloud" — dominated by soft blues, crisp whites, and rounded, friendly geometry.

## Color Palette

### Primary Colors
-   **AppBlue**: `#5885AF` (Primary Action, Brand Color) - _Adjusted to be softer than efficient blue, more like the reference image._
-   **LightBlue**: `#C3E0E5` (Secondary backgrounds, cards)
-   **PaleBlue**: `#EAF4F6` (Main background)
-   **White**: `#FFFFFF` (Card surfaces, inputs)

### Text Colors
-   **PrimaryText**: `#274472` (Dark Blue/Navy - High contrast against white/pale blue)
-   **SecondaryText**: `#829db0` (Muted Blue-Gray)

## Typography
-   **Headings**: System Rounded (Bold/Heavy) - Friendly but substantial.
-   **Body**: System Design (Default) - Clean and legible.

## Component Styles

### Cards
-   **Background**: White
-   **Corner Radius**: 24pt (Large, friendly curves)
-   **Shadow**: Soft, diffused blue shadow.

### Buttons (Primary)
-   **Background**: AppBlue
-   **Text**: White (Bold)
-   **Corner Radius**: Capsule (Fully rounded) or 16pt.
-   **Height**: 50pt min.

### Layout
-   **Padding**: Generous. 20pt standard horizontal padding.
-   **Spacing**: Elements should breathe. 16-24pt gaps between major sections.
